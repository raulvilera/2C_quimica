## Apps Script

O arquivo `Code.gs` contém o backend que cria a aba, registra as respostas, calcula as questões objetivas e corrige as discursivas com Gemini. Para publicar, autorize o escopo do Apps Script, configure a propriedade `GEMINI_API_KEY`, publique como Web App e coloque a URL `/exec` na constante `APPS_SCRIPT_URL` do `index.html`.

O frontend está publicado pelo GitHub Pages.
